# Platform Frontend SPEC

## 1. 选型

采用 **React + TypeScript + Vite**。理由：

- 人才供给和社区生态广，便于后续交接；
- TypeScript 可约束扫描状态、Finding 和权限等复杂数据；
- React 只负责视图，业务逻辑通过后端 API，避免绑定特定扫描器；
- Ant Design 适合企业后台的表格、授权、表单和审计页面；
- TanStack Query 处理异步查询、轮询和缓存；ECharts 展示趋势。

不把前端作为 API 网关：前端不保存扫描器密钥，不直接访问对象存储或扫描器控制端口。

## 2. 信息架构

```text
登录 / SSO
项目
  概览
  扫描任务
  风险清单
  依赖 / SBOM
  趋势
  策略与例外
组织
  用户与角色
  扫描配置
  集成 / Webhook
  审计日志
运行
  Runner 健康
  数据源同步
```

## 3. 核心页面

### 项目概览

- 当前风险按严重性、置信度、类型和状态统计；
- 最近扫描、趋势和失败原因；
- 未处理高风险、即将到期例外、数据源陈旧告警。

### 风险清单

- 服务端筛选和游标分页；
- 固定列：风险、规则/漏洞、位置或组件、来源、状态、负责人、更新时间；
- 支持保存筛选条件、批量指派和导出；
- 不能只在当前页做筛选或批量操作。

### Finding 详情

- 风险解释、规则/漏洞源、置信度、受影响版本或代码路径；
- 证据、修复建议、历史事件和相关发生位置；
- 状态变更：确认、修复、误报、接受风险、重新打开；
- 操作按钮按权限显示，但后端仍必须校验。

### 扫描任务

- 选择引擎/profile、代码来源或已授权目标；
- 显示排队原因、阶段、进度、日志摘要和取消；
- 失败时显示可操作错误，而不是只显示 500；
- 明确扫描数据保留时间和权限。

### DAST/IAST 高风险页

- 显著展示授权范围、环境、维护窗口和 Agent 到期时间；
- 提供紧急停止和一键卸载入口；
- 不展示可被轻易复制的完整凭据/请求体；
- 生产环境和过期授权使用强提示。

## 4. UI 状态与交互

- 首次进入空状态引导“连接仓库/上传代码 -> 创建项目 -> 扫描”。
- 扫描中允许轮询，页面隐藏后降低轮询频率；长任务用状态事件或 SSE 作为后续优化。
- 所有写操作显示提交中、成功、失败和可重试状态。
- 表格保留最近筛选和排序；URL 可分享当前筛选。
- 任何数字必须标明统计范围和时间窗口；空数据不显示为安全。
- 严重性不只是颜色区分，使用文本 + 图标 + 可访问对比度。
- 支持中文优先，所有文案通过 i18n key 管理；为英文扩展保留空间。

## 5. 权限与数据

- 页面和按钮根据权限元数据渲染，最终授权在后端。
- 不把 token、Cookie、完整扫描证据放入 URL 或浏览器持久化。
- 前端错误上报需脱敏，禁止抓取表单中的源码、凭据和敏感参数。
- 下载按钮只使用后端短时 URL，并处理过期和权限拒绝。
- 退出登录清理查询缓存、localStorage 中的非敏感偏好和 websocket/SSE 连接。

## 6. 视觉与工程质量

- 设计 token：颜色、间距、字体、控件状态集中在 theme；
- 业务组件与通用组件分离；
- 所有路由支持加载、空、错误和无权限状态；
- 响应式优先支持 1280px 以上，1024px 可操作；移动端用于查看和紧急操作；
- 键盘导航、焦点可见、表单错误与标签关联；
- 单元测试覆盖状态转换/筛选转换，API mock 覆盖服务端错误，Playwright 覆盖关键流程；
- 构建产物可在内网离线托管。

## 7. API 协作

前端只通过生成的 TypeScript client 调用后端。字段命名、枚举和错误码以 OpenAPI 为源；暂未定型的字段放显式 `extensions` 或有版本的引擎详情，不在多个页面各自解析原始报告。

建议的查询缓存：

- 项目摘要 30 秒；
- 扫描状态 3-5 秒，任务结束后停止轮询；
- Finding 列表 30 秒，写操作后失效；
- 用户/项目权限 5 分钟，权限变更后立即失效。

## 8. 验收标准

- 研发可以在 3 个页面内从项目进入扫描详情和风险详情；
- 安全人员可以筛选、指派、复核并关闭结果；
- 失败扫描与无风险扫描视觉和数据上明确区分；
- 未授权用户无法通过 URL 或直接 API 查看其他项目数据；
- 1280px 和 1024px 下关键操作可用；
- 关键流程具备端到端测试，所有文案支持统一国际化。
