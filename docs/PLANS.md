# 交付计划

当前已完成阶段 0，并进入阶段 1/2 的 Java 纵向 PoC。以下按退出条件组织，不承诺未经验证的自然日工期。

## 阶段 0：立项验证

目标：确认范围、风险和首个工程路径。

退出条件：

- `QUESTION.md` 的 P0 问题有结论或明确暂缓影响；
- 首批语言/仓库样本和容量基线确定；
- 候选引擎许可证、离线能力和商业使用条件有记录；
- 形成首个可验证的 CI 调用场景。

## 阶段 1：平台内核

当前进度：PoC 已实现登录、项目、上传、异步任务、结果和审计表；OIDC、完整审计和容器级集成测试未完成。

目标：不依赖真实扫描器，打通任务、权限、结果和审计。

范围：

- OIDC/项目/RBAC/审计；
- PostgreSQL、对象存储、数据库任务租约；
- Scan 状态机、幂等 API、Finding 模型和假引擎；
- React 项目、任务和风险列表基础页面。

退出条件：

- 假引擎可完成创建、执行、回报、取消和失败闭环；
- 跨项目访问和对象下载越权测试通过；
- OpenAPI 和前端 client 契约一致。

## 阶段 2：SCA + SAST MVP

当前进度：Maven SCA 已完成基本闭环；Joern 仅完成 CPG 适配骨架，SAST Finding 查询和前端展示未完成。

目标：覆盖公司主语言，形成代码扫描主流程。

范围：

- 首批生态的 SBOM 和漏洞匹配；
- 至少一个 SAST 主引擎和统一适配；
- 固定样本回归和误报/漏报基线；
- SARIF、JSON 和 CI 轮询/Webhook。

退出条件：

- 黄金仓库可重复通过；
- 同一问题可稳定去重并保留来源；
- 扫描失败与零发现可区分；
- 临时源码和结果过期清理可验证。

## 阶段 3：DAST 受控试点

目标：在明确授权的测试目标上形成黑盒扫描能力。

退出条件：

- 目标登记、审批、范围检查和出口白名单可用；
- 重定向/DNS rebinding/云元数据逃逸测试通过；
- Baseline 和 OpenAPI 扫描可取消、可复测；
- 证据脱敏和配额有效。

## 阶段 4：IAST 单运行时试点

目标：针对一个授权测试环境验证灰盒检测和 Agent 生命周期。

退出条件：

- Agent 注册、心跳、回收和强制卸载可用；
- 性能影响在事先确认的预算内；
- 敏感数据不会进入日志或标准化报告；
- 与测试流量建立可追溯关联。

## 阶段 5：治理与规模化

目标：从“能扫”进入“可长期运营”。

范围：

- 风险策略、例外、SLA、通知和工单；
- 数据源同步监控、证据保留和灾备；
- 配额、容量、规则发布和引擎升级流程；
- 使用指标与安全效果评估。

## 计划更新规则

- 阶段范围变化更新本文件和活动执行计划；
- 未经基准验证，不承诺漏洞检出率、误报率或截止日期；
- 阶段完成后把执行记录移到 `exec-plans/completed/`，并在质量评分中记录证据。
