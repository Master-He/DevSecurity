# Harness Engineering 目录笔记

用户指定的参考文章：

<https://openai.com/zh-Hans-CN/index/harness-engineering/>

本仓库借鉴的工作方式：

- 将架构、产品规格、设计决策、执行计划和参考资料显式入库；
- 让人和自动化 Agent 都能从 `AGENTS.md` 开始导航；
- 使用小而可验证的增量执行计划，并在完成后保存证据；
- 让“生成的 schema/文档”与代码一样受版本管理；
- 将未决问题、债务和产品质量标准写成可追踪文件。

本仓库不声称复刻文章中的具体产品实现。所有工程决策以本项目需求的验证结果为准。
