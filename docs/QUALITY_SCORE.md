# 质量评分

本文件定义实现阶段的验收维度。当前状态：**平台/SCA PoC 已完成基本构建和本地 API 闭环，未进行生产级容量、故障注入或浏览器 E2E 验证，因此尚未正式评分**。

| 维度 | 权重 | 通过条件 |
|---|---:|---|
| 功能正确性 | 30 | P0 用户旅程可完成；固定样本结果可重复；错误和部分成功状态真实 |
| 安全 | 25 | 权限/对象访问/Secret/目标范围测试通过；无越权和高敏日志 |
| 可靠性 | 20 | 任务租约、重试、取消、崩溃恢复、清理路径有测试 |
| 可维护性 | 10 | 适配器隔离、OpenAPI 契约、规则/数据源版本化、文档同步 |
| 用户体验 | 10 | 核心路径清晰，空/错/未授权状态完整，关键页面可访问 |
| 运维与可观测性 | 5 | 指标、日志、审计、告警和运行手册完整 |

等级：

- **A：90-100**，所有 P0 门禁通过且有证据；
- **B：75-89**，无高危缺陷，少量非阻塞缺口；
- **C：60-74**，功能可用但存在明确风险；
- **D：<60 或任一 P0 安全/越权测试失败**，不得进入生产试点。

## 初始质量门槛

正式试点前必须达到：

- 功能、安全、可靠性均不低于该维度的 80%；
- 不存在未处理的 P0/P1 越权、凭据泄漏、目标范围逃逸；
- 扫描失败不能显示为成功；
- 删除/过期清理必须经过故障路径测试；
- 至少一个真实结构（脱敏）项目完成端到端验证。

## 证据

当前证据：

- Spring Cloud 三个模块 Maven 构建通过；
- 后端 ZIP 路径安全和 JWT 单元测试通过；
- React TypeScript 检查与 Vite 生产构建通过；
- Go SCA 单元测试、`go vet` 和构建通过；
- 本地 H2/文件存储 profile 完成登录、建项目、上传 ZIP、异步 SCA 和结果查询；
- 本地 HTTP Git 仓库完成受控拉取、异步 SCA 成功；
- Maven dependency tree 成功路径验证了直接依赖与传递依赖；
- 样例返回 19 个 Maven 组件、5 个已知漏洞，并验证 Maven 失败回退 POM 解析；
- Docker Engine 在交付环境中未成功启动，Compose 端到端尚未验证。

每轮评分需链接测试报告、基准样本、缺陷记录和版本。没有证据的维度按未评分处理，不按“看起来完成”给分。
