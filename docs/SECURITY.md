# 安全设计

## 安全目标

- 只允许授权用户扫描授权项目/目标；
- 扫描器无法获得平台管理面或宿主机的任意控制权；
- 源代码、证据和凭据按最小权限处理并可审计；
- 外部集成不会绕过项目级授权；
- 高风险操作可停止、到期和回收。

## 威胁模型

潜在攻击者/风险：

| 威胁 | 影响 | 控制 |
|---|---|---|
| 恶意源码或依赖包 | 扫描器 RCE、读取宿主机/凭据 | 一次性容器、非特权、只读根、默认断网、资源限制、无宿主凭据 |
| 归档路径穿越/压缩炸弹 | 覆盖文件、耗尽磁盘 | 安全解包、路径规范化、文件数/解压比/大小上限 |
| DAST SSRF/重定向逃逸 | 访问管理网或云元数据 | 目标登记、出口白名单、运行期 DNS/IP 校验、禁止保留地址 |
| IAST Agent 被滥用 | 应用性能下降、敏感数据泄漏 | 非生产授权、签名 Agent、最小上传、硬超时、卸载和审计 |
| 跨项目 IDOR | 代码/结果泄漏 | 资源级 RBAC、租户条件查询、下载二次授权 |
| Secret 泄漏 | 外部系统或目标被接管 | Secret Store、短时注入、日志脱敏、仅一次性展示令牌 |
| 恶意报告/HTML | XSS、文件解析漏洞 | schema 验证、大小限制、前端净化、隔离预览 |
| 漏洞数据投毒 | 错误结论/供应链风险 | 源白名单、签名/哈希、schema 校验、快照回滚、多源比对 |
| Webhook 重放 | 重复触发自动化 | HMAC、时间戳、事件 ID、幂等消费说明 |

## 安全边界

- 控制面：API、数据库、对象存储元数据、策略和审计。
- 执行面：Runner 仅能读取任务输入和写入专属结果前缀。
- 数据同步面：只有同步服务可访问外部漏洞/组件源，且速率与来源受限。
- 目标网络：只有 DAST 专用出口代理可访问授权目标。
- Agent 面：Agent 只与平台注册/上传端点通信，不开放任意命令通道。

## 认证与授权

- 首版使用 BCrypt 本地账号和短时 JWT；初始管理员密码由部署时生成，禁止固定默认密码；
- 后续接入 OIDC Authorization Code + PKCE，并保留项目级授权边界；
- 服务账户使用限定项目、scope 和过期的令牌；
- 管理操作要求更强认证或二次确认，具体由 Q-002 决定；
- 所有资源查询自动附加租户/项目作用域；
- 默认拒绝，权限变化写审计并使前端权限缓存失效。

## 数据处理

- 源码和原始报告按数据分级存储，生命周期到期自动删除；
- 证据默认脱敏，完整证据下载需要额外权限；
- 临时目录在成功、失败、超时和取消路径都会清理；
- 生产日志禁止高敏字段；错误报告使用固定白名单；
- SBOM 也可能暴露内部依赖，按项目资产处理。

## 供应链

- 第三方引擎、规则包、Agent 和容器镜像锁定版本并记录来源；
- 升级前执行基准回归和安全检查；
- 构建使用受控基础镜像和镜像仓库，禁止从非白名单地址直接拉取；
- SAST/SCA 工具本身需纳入依赖扫描和漏洞响应。

## 发布门禁

任何扫描能力试点前必须证明：

- 未授权项目/目标/对象访问失败；
- 逃逸、重定向和路径穿越测试通过；
- Secret 不出现在日志和下载以外的不受控位置；
- Runner 请求权限最小化；
- 清理和回收在异常路径经过测试；
- 发现高危安全缺陷时具备紧急禁用开关。
