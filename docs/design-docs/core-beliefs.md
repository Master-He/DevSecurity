# 核心信念

1. **仓库是长期协作界面**：架构、决策、验收和运行知识必须在仓库中可读，不依赖个人记忆或聊天记录。
2. **可验证优先于宏大覆盖**：先覆盖真实主语言和真实流水线，再扩展语言列表。
3. **工具是可替换部件**：平台拥有统一结果模型和策略，引擎通过适配器接入。
4. **失败要显式**：未完成、数据陈旧、部分成功和零发现必须可区分。
5. **权限和安全在数据边界执行**：UI 隐藏不能代替服务端授权。
6. **扫描恶意输入按高风险处理**：所有源码、归档、报告和插件都可能不可信。
7. **Agent 有生命周期**：任何侵入式能力都必须能停止、卸载和证明已清理。
8. **例外需要期限和审计**：误报和风险接受不是永久删除。
9. **先测量再承诺**：准确率、性能和 SLO 需要样本与基线。
10. **尽量减少运维面积**：中小规模优先简单、可观测的组件，复杂度由需求证明。
