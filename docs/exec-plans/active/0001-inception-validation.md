- P0 问题有结论或明确对计划的影响；
- 至少一个 CI 调用场景和一组黄金样本可用于阶段 1；
- 所有文档链接有效，无“已实现”虚报；
- 风险接受、目标授权、IAST 环境边界都有明确责任人。

## 风险

- 语言/引擎覆盖范围过大，导致无法收敛；
- 没有真实样本，准确率承诺不可验证；
- 漏洞数据源许可证或网络限制被低估；
- 过早实现平台 UI 而结果模型不稳定；
- DAST/IAST 授权流程未打通，后续试点被阻塞。
