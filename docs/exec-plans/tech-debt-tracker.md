# 技术债跟踪

当前为立项阶段，以下为需要在实现前解决的设计债。

| ID | 债务 | 影响 | 关闭条件 | 状态 |
|---|---|---|---|---|
| TD-001 | 平台 API 尚未形成完整 OpenAPI 文件 | 前后端和 CI 无法做契约测试 | 生成 OpenAPI 3.1 并通过 lint | open |
| TD-002 | Finding JSON Schema 仍是设计表 | 适配器无法统一验证 | 发布 schema 和兼容测试 | open |
| TD-003 | 数据库 schema 是概念模型 | 无法实施迁移和索引评审 | 生成 migration 和 ER 图 | open |
| TD-004 | SCA 数据源许可、更新方式和离线镜像未确认 | 可能无法分发或无法更新 | 完成 Q-005/Q-006 评估 | open |
| TD-005 | SAST 引擎选型未做真实基准 | 覆盖和性能未知 | 同一黄金样本对候选引擎评比 | open |
| TD-006 | DAST 出口代理和 DNS 范围验证未实现 | 存在 SSRF/范围逃逸风险 | 安全测试和部署文档通过 | open |
| TD-007 | IAST Agent 协议和运行时支持未验证 | 稳定性和隐私风险 | 单运行时靶场闭环 | open |
| TD-008 | 设计 token、组件库和页面原型未建立 | 前端实现可能碎片化 | 设计评审和可访问性基线 | open |
| TD-009 | 未定义备份恢复演练周期在部署中的具体实现 | 数据恢复目标不可验证 | 生产部署手册与演练记录 | open |
| TD-010 | 容量和安全 SLO 仅有假设 | 无法验证数百人规模可用性 | 压测和 Q-011 结论 | open |

新增债务必须包含影响、关闭条件和负责人；不要用“以后优化”作为关闭条件。
